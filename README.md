<h1 align="center"> Jogo de Quebrar Blocos (Breakout) </h1>

# 🚧 O que é esse projeto?

Uma recriação moderna do clássico jogo Breakout desenvolvida em Python utilizando a biblioteca Pygame. O projeto conta com arquitetura Orientada a Objetos (POO), efeitos sonoros gerados por síntese de áudio dinâmica (sem necessidade de arquivos de mídia externos), sistema de partículas e power-ups.

# 🎮 Jogabilidade.

- Seta Esquerda e Seta Direita:	Movem a raquete.
- Espaço:	Iniciar o jogo (Na Tela de Menu Inicial).
- Tecla R:	Reiniciar a partida (Na Tela de Game Over / Vitória).
